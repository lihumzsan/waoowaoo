# 视觉开发与资产设计

## 作用

把故事与用户要求转化为统一视觉风格以及可复用的角色、场景、道具和参考资产设计。本 Skill 汇总现有中英文资产 Prompt 的有效规则并使用同一基线，避免不同语言得到不同设计纪律。

## 视觉风格系统

- 视觉风格只决定美术媒介、画面滤镜、总体质感和色彩基调，不替导演决定叙事视角、表演、信息节奏、焦段、运镜、视频剪辑或声音。
- 区分跨图片与视频共享的总体视觉风格，以及只供资产图片使用的灯光、材质细节和构图规则。视频生成使用总体视觉风格，不应继承资产板专用构图。
- 风格摘要方便人理解；真正用于生成的风格描述必须具体、可执行，不能只写“电影感”“高级”“梦幻”等抽象评价。
- 导演、影片、工作室、流派或年代引用应转写为可执行的媒介、材质、色彩、轮廓、细节密度和画面处理特征，不依赖受保护名称本身。
- 多个风格候选应忠于同一剧情事实，在美术媒介、总体质感、色彩与设计语言上形成实质差异，而不是只做轻微调色。
- 风格预览服务于比较视觉方向；不得借预览改变人物身份、场景事实或剧情内容。

## 角色设计

### 人类角色的可见信息

- 明确性别呈现和具体年龄感。
- 描述脸型和可见五官特征、眼睛形状与大小，但不描述眼睛颜色。
- 描述头发颜色、长度、发型与发质。
- 描述身高感、体态、肩宽、腰线和整体轮廓。
- 皮肤只写质感和可见标记，如粗糙、光滑、雀斑、胎记、疤痕或纹身；禁止肤色、唇色、脸色和其他身体部位颜色。
- 服装写清款式、年代、材质、配色、结构和细节；鞋子是完整人物设计的必要部分，必须写款式、材质和颜色。
- 只添加能加强身份和复用性的可穿戴配饰，例如眼镜、耳饰、项链、手表或戒指。
- 服装、发型、鞋履和配饰必须符合故事年代与社会背景。

### 非人类角色

- 动物、神话生物、非人形生物或明确的风格化形象不强套人类外貌模板。
- 描述从角色名或物种名开始，围绕形态、轮廓、表面、关键器官、服饰和核心辨识特征展开。
- 修改时保留其身份锚点，只改变用户明确要求的部分。

### 角色描述纪律

- 角色资产描述只写稳定外貌，不写表情、姿态、动作、背景、环境、手持剧情道具或故事性句子。
- 不用“或”“可能”“也许”“大概”等不确定词；每个视觉选择明确具体。
- 不写“气场强大”“成熟稳重的气息”等无法直接看见的抽象气质。若需要表达身份能量，应转译为可见轮廓、服装、材质和配饰。
- 以原文明确外貌为最高优先级，但仍遵守身体颜色限制和当前安全边界。
- 角色描述不混入艺术风格、滤镜和光影；这些由视觉风格系统统一追加。
- 在不过度锁死的前提下保留合理生成空间。除非输入要求，不规定每根发丝、每个色块或每件配饰。

## 参考角色图

- 从参考图提取脸部结构、发型、体型、服装结构和可穿戴配饰等稳定身份特征。
- 参考图只展示局部身体时，根据可见服装与角色身份合理补齐下装、鞋履、手臂和手部；补全部分必须与已见部分协调。
- 图像反推仍不得描述肤色、眼睛颜色、表情、动作、背景和姿势。
- 反推分析可以给出由画面直接支持的整体造型或气质关键词，帮助理解身份方向；进入最终生图描述时，必须把这些关键词转译成可见的轮廓、服装、材质和配饰，不能留下无法视觉化的抽象判断。
- 用户或项目风格高于原图画风。参考图用于身份，不能覆盖明确指定的美术风格；忽略原图偶然色调、光线、模糊、噪点和瑕疵。
- 转成资产板时，保持正常美观的人体比例、完整服装鞋履和主要可穿戴配饰；表情自然平静，身份锚点稳定，背景只服务风格而不绑定剧情地点。最终图片必须清晰锐利、细节丰富并达到专业生产质量，不复制参考图的模糊、噪点或瑕疵。
- 简单角色参考默认优先单一角色、身份清楚、轮廓完整和稳定服装，不自动生成宫格、多视图或动作分解；只有交付明确要求资产板时才使用资产板设计。
- “角色描述不写姿态或动作”约束的是稳定身份正文和普通单图。明确交付候选资产板时，可以在资产板指定区域加入与职业或身份相符、可复用于分镜的轻微姿态或语境样本；这些样本不得改变角色身份、变成剧情事件，或污染稳定身份描述。

## 角色候选

- 候选必须是同一角色身份的不同设计方向，不是不同角色。
- 可以分别强化：身份与轮廓忠实度、服装/材质/年代质感、角色能量与视频参考可用性。
- 候选差异应清楚但仍共享角色核心身份；不要通过改变年龄、物种、关系或剧情事实制造假差异。
- 若有视觉风格，选角、服装、色彩、材质和氛围必须与之兼容。

## 场景设计

- 从明确的场景名称或空间身份开始，把泛称具体化为稳定可控的真实空间，而不是停留在“教室”“办公室”等标签。
- 忠实保留用户指定的核心场景身份、关键物体、材质、时代感和空间关系，不能替换为更熟悉但无关的场景类型。
- 写清建筑与空间结构：墙、地面、天花、门窗、边界、开口、尺度和纵深。
- 材质、颜色和表面状态具体可见；加入有叙事价值的使用痕迹、生活痕迹与陈设，避免泛化美术词。
- 明确前景、中景、背景或近处、中部、远处的层次，保持完整全景和可理解的空间边界，不生成局部裁切或含糊背景。
- 设置至少三个稳定、清晰可见的空间锚点，并在其周边保留可用地面或空白区域，供后续人物落位；这只是隐形构图指导，不能画标签、轮廓框、箭头、引导线或人工占位。
- 新建最终场景生图描述时，光线应包含真实来源、位置、时间和对空间的可见效果。修改作为项目事实保存的基础地点描述时，只保留物理光源与照明条件，不写由视觉风格统一追加的戏剧化光影效果；最终生图 prompt 再把基础地点事实与资产图片风格合成。任何资产专用灯光规则都不能被误写为跨媒体总体风格。
- 私密空间或明确空镜不加入人物。宴会厅、集市、上课教室等天然有人群的场景可以加入模糊、无身份的人群，不能引入有名主角或剧情动作。
- 场景资产应是可复用的环境建立画面，不是某个瞬间的叙事分镜。不要出现对白、字幕、解释文字、水印、标注、箭头或 Logo。
- 场景世界中自然存在的招牌、路标、门牌、海报、包装或屏幕文字只有在属于环境时保留，并保持次要自然，避免随机乱码和漂浮文字。

## 场景候选

- 选择最适合后续视频参考的单一场景，不机械复述输入中第一个地点。
- 基准方向忠实还原空间身份、结构、锚点、材质、光线和可落位区域。
- 叙事核心方向选择最能承载冲突、揭示、反转、持续压力或情绪转折的地点，通过建筑、负空间、物件摆放、动机光源、色彩和材质体现张力，而不是写解释。
- 电影美术质感方向根据年代、类型、阶层感、情绪温度和潜台词，强化布局、家具、道具、表面、使用痕迹、实景光源、空气、反光和阴影，使每个重要元素都有作用。
- 各候选仍必须是空场景、完整环境和可复用参考，不能通过加入不同剧情事实制造差异。

## 道具设计

- 只描述道具本体的静态视觉信息：主体结构、轮廓、数量关系、材质、颜色、表面处理、纹样、装饰和磨损。
- 不写用途、剧情、角色动作、人物、手部、桌面、房间、背景、镜头或氛围光影。
- 结果适合白底居中、主体完整清楚的独立道具资产图。
- 参考图可提供轮廓、结构、材质、纹样与配色，但不能引入参考图中的偶然背景或人物。

## 修改已有资产

- 先识别用户要求改变的具体视觉特征，再准确替换或补充相关部分。
- 保留所有未被修改的原有身份、结构、材质、颜色、装饰和风格事实。
- 有参考图片时只吸收与修改目标相关的关键视觉特征，不让参考图覆盖用户已确认内容。
- 修改后重新检查整段描述的流畅性、一致性、时代感和资产类型边界。
- 场景修改如果增加或删除关键锚点，必须同步更新空间结构、层次和落位空间；不能退化为泛场景。

## 自检

- 风格规则是否清楚区分跨媒体视觉风格与资产图片专用灯光/材质/构图？
- 角色是否稳定、完整、年代一致、鞋履明确，并排除了身体颜色、动作、背景、不确定词和抽象气质？
- 非人类角色是否按真实形态处理而非套用人类模板？
- 场景是否忠实、结构完整、层次清楚、锚点稳定，并留有无标记的落位空间？
- 道具是否只包含静态本体信息？
- 候选是否产生有意义差异但不改变身份和剧情事实？
- 修改是否保留所有未被要求改变的特征？

## 边界

本 Skill 负责视觉设计方法。输出长度、候选数量、JSON 格式、图片画幅、provider 参数、真实人物安全策略和最终图片 Prompt 后缀由调用方与执行层定义。
