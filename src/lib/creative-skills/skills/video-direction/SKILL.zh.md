# 视频导演与生成设计

## 作用

把已确认的剧情、镜头意图、角色/场景/道具参考和声音要求转化为可直接交给视频生成模型的完整设计。重点是引用明确、时间可执行、动作有入口与落点、片段内部连续、独立片段接缝可信，并正确利用模型的原生同步声音能力。

## 何时直接设计视频

- 单个短镜头可以从用户目标直接形成最终视频提示词，不要求先建立完整剧本、Bible 或专业时间线。
- 多镜头、多片段或需要最终组合的作品，应先获得足够的镜头顺序、时长和连续性事实，再分别生成可独立成立的视频片段。
- 只设计最终结果真正会使用的角色、场景、道具或 UI 参考，避免无关素材稀释身份与场景优先级。

## 参考素材

- 使用有明确顺序的参考清单，并在最终提示词中用“图片1中的人物”“图片2中的场景”“图片3中的道具”精确对应；不要只写资产名、文件名、内部 ID 或聊天代称让模型猜。
- 按叙事重要性和首次使用顺序排列。通常优先放身份最重要的角色，再放关键道具或必须呈现的 UI，最后放按首次出现顺序使用的场景；当前故事重点高于固定模板。
- 每张图只承担清楚的主要职责。只传当前片段实际使用的素材，并遵守目标模型真实参考数量上限；不得自行截断、替换或重排用户锁定的引用。
- 要求模型保持已批准的人物身份、服装、轮廓、场景结构和道具设计，但不要让参考图中的偶然姿势、光线、噪点或构图覆盖当前视频要求。
- 手机消息、屏幕卡片或必须在视频内出现的关键 UI 可以作为图片参考，要求模型在世界内呈现；只有用户明确要求后期图层时才设计成覆盖层。

## 最终视频提示词

- 使用与用户内容和对白一致的语言。
- 开头简洁说明视频总时长、画幅、题材和总体视觉风格，然后按时间顺序写镜头；最后只附与当前视频直接相关的连续性和质量要求。
- 每个镜头以明确时间段组织，依次给出景别、一种主要运镜、使用的图片引用、可见地点、人物或道具、动作与表演、逐字对白和同步声音。逐字对白统一写成 `{逐字台词}`，短同步声音统一写成 `<声音描述>`，不要只用自然语言含糊混在一起。
- 提示词必须描述模型需要生成的完整画面与声音，不解释制作流程、系统规则、测试原因、内部数据结构或项目状态。
- 保持充分但简洁：只带入当前镜头相关事实，不复制完整项目档案、全部规范或无关禁词。
- 输出是单一全画幅连续视频，不生成拼贴、网格、分屏、联系人表、字幕、标题或文字覆盖，除非用户明确要求且模型能力支持。

## 镜头和场景切换

- 新地点出现时，只使用“镜头切至图片N中的……”这类轻量标记，然后直接描述新镜头已经成立的取景与动作状态。
- 不向生成模型详细描述硬切、跳切、软切、叠化、匹配剪辑、动作峰值、J-cut、L-cut、遮挡切、擦镜、物体擦过镜头、物体遮满或填满画幅等转场机制；这些词容易被错误渲染成可见内容。
- 不要求模型在互不相连的场景参考之间发明走廊、楼梯、门厅或其他连接空间。
- 中间过程不影响理解时直接切到新地点；走路、开门、奔跑、乘坐或抵达本身承担剧情时，才为它保留真正的动作镜头。
- 切换后的镜头从新状态开始，不把独立场景写成必须连续插值的一条运动路径。

## 动作设计

- 根据时长安排少量、有先后顺序的动作节拍，每个动作都有可见落点。通常一段短镜头只承载一到三个核心动作。
- 不用一个过短动作填满长镜头，否则模型容易重复表演；也不在短时长内塞入无法完成的复杂动作链。
- 写清镜头开始时的可见状态和结束时达到的状态。人物已经站定、拿到道具、坐下、转身或到达后，下一镜头从结果状态开始，不无意重演。
- 剧情依赖朝向或视线时，写成可见事实，例如“背对镜头面向壁画”“侧身看向走廊尽头”“抬头看向海面巨物”，不只写“观察”或“看见”。
- 多人物高风险镜头可以简洁要求每个角色只出现一个实例；不要堆叠“只发生一次、不得返回、不得再次经过”等防御句，优先用清楚动作节拍消除歧义。

## 连续性

- 只延续对当前片段重要的事实：人物身份与服装、身体状态、运动速度和主要动线、情绪强度、道具持有者、关键场景物、时间与环境色调以及持续声音。
- 连续性写成画面和声音事实，不使用剪辑元语言。
- 核心道具、祭坛、轿子、车辆或其他重要场景物在后续仍需存在时明确写出，不无理由新增参考图没有的新物体或复制核心结构。
- 同一生成片段中的镜头共享必要空间与动作连续性；不同独立生成片段保持状态相容，但不假装是同一次无缝拍摄。
- 每个片段使用准确的入口状态，并在结束处形成后续可继承的出口状态。

## 节奏、空镜和情绪释放

- 根据题材在开场使用有叙事作用的短空镜或环境动作快速建立地点、尺度和气氛，不机械给每个场景加空镜。
- 空镜、反应和道具特写只有在承担信息、悬念、喜剧停顿、视线引导或气氛变化时使用。
- 重大揭示和宏大场面需要比普通动作更多时长，通常以“征兆或局部细节—完整揭示—人物反应或尺度对比”完成情绪释放。
- 喜剧和引流短视频优先保证前几秒钩子、反应停顿和笑点落点；剧情短片优先保证因果可理解，不为了快切省略理解事件所必需的动作。

## 长视频和独立片段接缝

- 超过模型单次时长时拆成多个各自完整的视频片段。每段承担明确的局部剧情与情绪任务，不把一个未完成动作切到两次独立生成。
- 前段最后镜头与后段第一镜头采用明显景别或角度差异，降低独立生成的人物站位变化被看作画面跳动的风险。
- 不用黑场、墙面、擦镜或遮满画幅的物体掩盖接缝。
- 相邻片段保持人物身份、服装、道具状态、运动强度、环境色调和声音氛围相容，但允许它们作为独立镜头自然切换。
- 需要一个完整文件时，为片段保留清楚顺序、真实时长和可组合的音画边界；只有调用方真实提供了视频组合能力时才能继续合成。没有该能力时必须明确告诉用户，生成片段本身不能虚构已经完成合成。

## 对白、声音和原生音频

- 当模型支持原生音频且作品需要对白或同期声时，让视频模型生成同步声音。
- 对白逐字保留，并明确说话者和其稳定固有声线；不要把对白替换成旁白。
- 使用 `{逐字台词}` 与 `<声音描述>` 明确区分逐字对白和短同步声音。动作镜头补充对应脚步、衣物、门、碰撞、机械、环境或物体声音。
- 需要声音延续时直接写“警报声持续”“海底低鸣渐强”等事实，不用 J-cut、L-cut 等术语。
- 恐怖、巨物和高潮场面可以使用有辨识度的低频、结构震动、异常生物声或空间回响，但声音必须服务当前画面。
- 视频原生同步声音与独立 BGM职责分开。不要无理由覆盖或重复已经生成的对白、同期声或环境声，也不要把音乐工具当配音或音效来源。

## 最终片段检查

- 每个参考编号是否精确指向对应人物、场景、道具或 UI？
- 每个镜头是否能在分配时长内完成，并有明确入口、动作顺序和落点？
- 场景切换是否从新状态直接开始，没有虚构连接空间或渲染剪辑术语？
- 人物身份、服装、身体状态、道具、动线、情绪、环境和声音是否保持必要连续？
- 对白是否逐字、说话人明确，声音是否与画面同步且没有重复独立音频层？
- 独立片段是否各自完整，并通过景别/角度差异形成可信接缝？
- 是否只包含当前视频所需信息，没有无关素材和内部说明？

## 边界

本 Skill 负责视频创作和最终提示词方法。资源 ID、revision、fingerprint、模型能力校验、参考上限、provider 参数、媒体提交、计费和严格执行模板由调用方与执行层负责。
