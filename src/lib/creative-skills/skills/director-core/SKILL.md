# 导演与制作时间线核心

## 作用

把已经成立的剧情事实转化为可执行的制作时间线：每个镜头承担什么叙事任务、画面中发生什么、人物如何表演、对白和同期声是什么、哪些连续镜头可以由模型一次生成，以及每个镜头使用怎样的景别、机位、构图和运镜。

这是单层的统一导演知识。调用方可以要求完整时间线，也可以只要求其中一个范围；只做局部范围时不得重写已经确认的其他部分。

## Skill 读取组合

- 当任务的 `outputKind=video_prompt_set` 时，在创作前必须同时读取 `director-core`、`video-direction` 和 `quality-review`。本 Skill 负责导演规划，`video-direction` 负责把适用知识写入唯一最终提示词，`quality-review` 负责输出前自检。
- 三份 Skill 是同一次通用 Worker 推理中的知识组合，不是三个串行 Subagent，也不产生三份结果。最终仍只返回 strict `video_prompt_set`，所有专业判断内化进每段唯一的 `prompt`。

## 事实边界

- 剧本、全局设定、入段状态、当前事件、已确认资产和用户要求是唯一剧情事实。
- 不创造剧本没有的对白、人物、地点、道具、动机或结果；对白必须逐字忠实。
- 资产受限时，只选择明确提供的角色和场景名称，不用近似名称或描述猜测身份。
- 导演规划组织事实，不获得修改世界设定和持续状态的权力。

## 镜头叙事结构

- 每个镜头必须有清楚目的，例如建立空间、推进动作、呈现反应、揭示细节、建立气氛或完成过渡。
- 镜头时长由可见动作、表演、对白、观众理解所需时间和情绪落点决定；不以固定模板给所有镜头相同时长。
- scene 说明已确认地点以及当前使用的局部区域；不要把同一地点的局部空间误建成新场景身份。
- action 只写画面中真实发生且会被观众看到的动作和变化，避免解释人物内心或拍摄过程。
- 每个出镜人物只描述可见表情、身体动作、停顿、反应和运动。不要把人物站位、屏幕坐标、视线坐标或摄影调度混进表演描述。
- 对白逐字保留，并确保说话人物确实出现在该镜头。没有对白时不要补旁白。
- 同期声只写与当前画面同步的短声音，如脚步、门、碰撞、衣物或机械声；不要把连续环境声底或 BGM 塞入镜头同期声。
- 空镜、反应、特写和转场镜头必须承担信息、尺度、悬念、笑点、视线引导或情绪变化，不能机械添加。
- 一个时间段内需要多个亚秒级短镜头时，作为一个快切组整体规划：整组共享一条动作链或一个母题、一条银幕方向和一个落点，只给整组时间段与 cut 数量，不给每个 cut 单独标秒。它是通用手段，连续动作的节拍切分、同一事件的反应链、进展压缩和开场钩子都适用，但不能用来填满时长。一个快切组按一个核心动作计入镜头承载量。
- 先判断镜头关系，再决定是否需要转场。同一时空的连续动作和普通角度变化通常自然衔接；只有时空跳跃、时间压缩、情绪转折或视觉隐喻确有价值时才设计创意转场。

## 场面调度与站位

- 把表演和场面调度分开思考：表演描述表情、身体动作和反应；场面调度描述人物在可见空间中的位置、朝向、关系与移动。
- 站位影响动作可读性、人物关系、构图或跨镜连续性时，明确首个可见布局和镜头结束落点。优先组合稳定实物锚点、画面区域或前中后景、身体朝向以及与道具或其他人物的关系，例如“站在海图桌左端、画面左三分之一，身体朝向风暴窗，右手按住黄铜无线电”。
- 使用自然画面区域和场景实物，不使用像素坐标或把摄影机调度混进人物表演。空镜、孤立道具特写和空间关系已经毫无歧义的细节镜头可以省略人物站位。
- 人物改变位置时，让起点、路径和落点成为可见动作；人物到达后，后续相关镜头用同一个实物锚点、区域、朝向或道具关系继承结果状态。
- 多人物镜头按叙事需要说明彼此距离、前后关系和所处场景锚点；只有动作方向或对视关系依赖空间轴线时，才明确保持银幕方向。

## 节奏与情绪释放

- 前几秒根据作品类型建立钩子、空间和主要冲突。快节奏不等于删掉理解因果所需的动作。
- 普通动作保持简洁；重大揭示、宏大场面和关键情绪需要“征兆或细节—完整揭示—人物反应或尺度对比”的充分时间。
- 喜剧重视反应停顿和笑点落点；悬疑重视信息控制和视线顺序；剧情片重视人物选择的因果；动作场面重视可读动线和落点。
- 按题材确定节奏档位：竖屏短剧和引流短视频按“观众仍能理解因果的最短时长”组织每个镜头，动作与对白尽量并行推进；情感慢戏、文艺片和悬疑铺陈按自然表演节奏，保留必要的沉默与呼吸。
- 可以压缩或一笔带过：赶路与位移、重复观察、只作说明的画外音、没有新信息的过场动作、简单的抓捕与制服过程。
- 必须给足时间：身份揭示、关键反应、笑点落点、威胁与关系反转、暴力落点、结尾钩子。快节奏档位同样不得压掉这些。
- 同时发生的对白、画外音、内心独白与画面动作在同一时间轴上推进，不按先后累加时长。
- 镜头之间应形成清楚的注意力流、动作流和情绪曲线，避免只追求孤立的漂亮画面。

## 生成分段

- 先完成镜头叙事与导演设计，再把连续镜头装入独立生成分段；分段不是预先套用固定秒数的镜头模板。
- 执行层提供的 `productionContext.video.allowedSegmentDurationsSeconds`、最大/最小时长和画幅是权威能力事实。内容确实足以支撑时，优先减少独立生成次数，把可连续的内容装到最大允许时长（当前能力通常最高 15 秒）；不能为了凑满时长或减少生成次数而重复动作、拖延表演、延长无信息停顿或添加空内容。
- 只有时空、人物状态、场景、未完成动作连续性发生断点，或需要精确匹配总时长余量时，才选择更短的允许时长。
- `durationIntent` 是唯一时长权威：`mode=fixed` 时全部生成分段时长之和必须准确等于 `seconds`；`mode=derive` 时总时长由内容真实需要决定，上下文中的规划估时（如 Chapter `targetDurationSec` 或节拍估时）只是参考事实，不是必须填满的预算。
- 将按顺序连续、能够共享动作、表演、空间、情绪和同期声连续性的镜头组成生成分段。
- 每个分段必须完整覆盖其镜头并遵守当前模型的单次时长上限；不能漏镜头、乱序或把不连续镜头强行合并。
- 不把一个未完成动作切到两次独立生成中。每个独立分段应有成立的开始状态、局部任务和结束落点。
- 快切组是分段内部结构，必须整组留在同一个生成分段里，不得拆到两次独立生成：最短允许时长通常是 4 秒，亚秒级 cut 无法成为独立分段，两次生成之间也没有帧级接力。
- 为每对相邻独立分段联合设计接缝。前段末镜头与后段首镜头使用可见不同的景别；同地点、同人物时，只换侧面、背面或轻微机位角度不能替代景别变化。景别变化是必要条件，不是充分条件：后段首镜头必须同时在时间上推进，不得复现前段已完成的动作节拍或已经展示过的状态瞬间。人物再次成为可识别的画面主体时，用稳定场景锚点继承其站位。
- continuity 只写该分段必须保持的动作、人物表演、空间、情绪、道具和同期声事实，不复述全部剧情，也不使用剪辑元语言。
- 如果时空或状态发生跳跃，建立新的分段，而不是让生成模型在互不相连的空间之间连续插值。

## 景别、机位、构图与运镜

- 景别服务信息与情绪：全景建立空间和尺度，中景呈现关系与动作，中近景兼顾表演和环境，近景呈现情绪，特写揭示关键细节。
- 每个镜头确定一个机位关系，例如正面、四分之三侧、侧面、过肩、背身、俯视或仰视。机位服务信息与人物关系；不因为没有做出判断就回落到正面平视。
- 每个镜头确定主体在画幅中的落位：三分线区域或前中后景层次、负空间方向，以及与场景锚点的纵深关系。相邻镜头不复用同一构图。居中构图必须有叙事动机，例如正式感、对称仪式、审讯压迫或单点凝视；没有动机时不得连续居中。
- 有人物出镜的镜头确定其视线落点，并落在场景内的具体对象上，例如屏幕中央的信号、走廊尽头、对面人物的手。只有剧情明确打破第四面墙（口播、vlog、独白、对镜头说话）时，视线才与镜头交汇。
- 亚秒级快切组是例外：组内每个 cut 只定景别和这一下发生什么，机位、落位与视线由整组共享的一条银幕方向或空间轴线统一，不逐 cut 指定——那个尺度上这三项不可感知，逐 cut 指定只会制造无法执行的假精度。组内秒级以上的镜头仍按普通镜头处理。
- 每个镜头选择一种主要运镜意图，例如固定、推近、拉远、横移、跟拍或环绕。运镜必须帮助观众看清动作、揭示信息或感受人物，不因“电影感”无目的运动。
- 稳定性与叙事相符：锁定或稳定适合空间、对话和控制感；平滑运动适合引导和沉浸；轻微抖动或手持只在主观压力、追逐或不稳定感确有价值时使用。
- 视觉风格可以影响运动质感和镜头呼吸，但不能借此改写剧情、表演或空间事实。
- 避免同时要求互相冲突的运动、无法在时长内完成的复杂轨迹，或让摄影机运动遮蔽关键表演。

## 完整时间线的一致性

- 剪辑意图和执行设计应共享同一个镜头引用。增删或重排镜头时，叙事、执行、生成分段和结果选择必须指向同一镜头概念。
- 先确定“为什么需要这个镜头”和“镜头内发生什么”，再决定景别、机位、构图与运镜；它们不能反向制造不存在的剧情。
- 人物已经完成站起、拿取、转身或到达后，下一镜头从新状态开始，不能无意重演动作。
- 相邻镜头沿同一时间轴严格递进：后一镜头第一帧呈现的时刻必须晚于前一镜头最后一帧。同一个动作节拍不得在相邻镜头中换景别再呈现一次——手掌已经拍在桌面之后，不能再接一个“手掌在桌面上”的特写把这一下重看一遍。身份、道具与站位全部连续且景别确实不同，仍然属于时间回退。
- 切点按边界类型选择。同一生成段内部的 Shot 边界，强动作优先切在动作进行中：前镜头承载节拍前半（手臂举到最高点并开始下压），后镜头从节拍后半进入（掌面砸落、桌面震动），运动方向与速度跨切口延续。独立生成段之间的切点必须落在动作节拍的完成落点上：前段以完成状态收尾，后段从下一个节拍开始，既不重看已完成的节拍，也不从未完成的中途接续——两次独立生成之间没有帧级接力，中途接续只会得到错位跳帧。
- 跨镜头保留人物身份与服装、身体状态、道具持有、主要动线、情绪强度、场景核心物和持续声音。
- 对相邻镜头检查入口与出口状态，确保动作方向、信息状态和观众注意力能够连接。

## 按范围交付

导演判断首先是内部创作过程。只有调用契约存在真实消费者时才单独交付过程结构；当目标是最终视频提示词时，把所有适用的镜头、表演、动作、连续性、声音和转场判断直接落实进那一份提示词，不再平行复述导演过程。

- 若只要求核心剪辑结构：只决定镜头目的、时长、场景、动作、表演、对白、同期声和生成分段，不额外写景别、机位、构图、视线落点、灯光、运镜或最终生成提示词。相邻镜头的时间递进与切点位置属于剪辑结构本身，仍必须决定。
- 若只要求镜头执行：完整覆盖输入镜头且保持原顺序，只补景别、机位角度、主体落位、视线落点、主要运镜和稳定性；不重写剧情、动作、表演、对白或同期声。
- 若要求统一 Production Timeline：在同一镜头下清楚区分 editorial、execution 和后续 result，但不让结果状态改变已确认创作事实。

## 自检

- 是否只使用已有剧情事实和确认资产，并逐字保留对白？
- 每个镜头是否有明确叙事作用、可见动作和可信时长？
- 表演与场面调度是否分开描述，必要站位是否使用可见实物锚点、画面区域、朝向和关系？
- 同期声是否只包含同步短声音，没有 BGM 或连续环境声计划？
- 生成分段是否连续、完整、在能力上限内，并避免跨次切断未完成动作？
- 景别、机位、构图和运镜是否服务叙事，没有覆盖或改写核心计划？每个有人物的镜头是否都有主体落位和视线落点，是否出现无动机的连续居中或无第四面墙动机的直视镜头？
- 使用快切组的地方，是否整组共享动作链或母题、银幕方向和落点，并整组留在同一个生成分段内？
- 相邻镜头的入口、出口、道具、人物状态和情绪是否连续，时间是否严格递进，是否存在同一动作节拍换景别复现？段内切点与跨段切点是否分别按动作进行中和完成落点选择？
- 是否逐对检查相邻独立分段，并让前段末镜头与后段首镜头形成真实可见的景别变化？

## 边界

本 Skill 提供统一导演方法。系统 identity、允许时长、严格输出 Schema 和执行参数由调用方与执行层定义。`outputKind=video_prompt_set` 时遵守上面的三 Skill 读取组合；其他任务根据目标只读取真正适用的知识。
