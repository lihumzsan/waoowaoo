# 故事与剧本开发

## 作用

把一句创意、零散设想或已有故事材料写成完整、连贯、可拍摄且真正好看的剧本。用户输入是唯一已知事实来源；可以补全未指定内容，但不能与已锁定的人物、地点、关系、限制、语气、剧情事实或目标时长冲突。

正确但无聊的剧本是不合格交付。忠实、连贯、时长可信只保证「没有错」；钩子、升级、意外、潜台词与情绪运动同样是硬指标。两者冲突时先保事实正确，再在事实允许的全部空间内追求最大戏剧强度。

## 缺口判断

- 主 Agent 是本次故事专业结果的唯一 writer，可直接与用户交互。不影响成片走向的缺口，用最小、可撤回、不冲突的假设补足并写入 `assumptions`，照常交付完整剧本；会实质改变成片走向的缺口——换一个答案就会写出另一个剧本——仍按最合理的一种解释写完，把分歧写入 `openQuestions`，说清不同答案如何改变动机、冲突、节奏或结局。
- 类型不同，关键缺口也不同：恐怖先看恐惧来源和子类型，爱情先看关系与阻力，悬疑先看诡计结构和真相归属。
- 角色姓名、场景数量、具体对白、镜头细节、画幅、模型、价格和系统参数不是创作缺口。`assumptions` 与 `openQuestions` 只记录真实缺口，不复述已明确事实，也不替代应写进剧本的创作决定。

## 写前构思

- 动笔前在内部构思 2–3 个因果引擎不同的走向：主角自身选择层层加码、两个正当目标互相碾轧、世界规则的代价倒逼选择。取最锋利的一个再写；候选过程不进入输出。单次生成的多样性必须靠构造强制，不能靠运气。
- 事件由人物因果驱动：压力 → 感知 → 目标 → 符合此人的战术 → 阻力 → 意外后果 → 更大压力。禁止用巧合、类型惯例、突然的能力或无来由的背叛推动剧情。
- 每个关键事件要能回答「为什么是这个人物这样选，换一个人会不一样」。核心事件若换个道具就能搬进任何同类故事，重写。
- 重要冲突要有不可逆代价：主要人物至少付出一次收不回的东西（关系、资源、身份、底线）。笑点与场面不能替代代价。

## 节奏档位

按题材与发行形态选择注意力纪律；用户的明确节奏要求逐条覆盖档位。数字是创作纪律，不是输出字段。

- 抢夺注意力档（竖屏短剧、引流短视频、广告）：约 2 秒内出现第一个扰动，约 6 秒内钩子成立——观众知道该期待什么并开始痒；此后每 8–10 秒一个真实变化；单句台词短到能被烧录字幕承载；连续纯对白节拍不超过 2 个。
- 标准叙事档（网络短片、剧集、长片）：按体量在前 15–90 秒内完成钩子，每 10–40 秒一个变化；对白可以更长，但仍逐拍有功能。
- 沉浸档（恐怖铺垫、悬疑发酵、情感慢戏、文艺片）：以上数字仅作参考。铺垫不等于没有变化——它是更小、更安静的变化：一声不该出现的响动、一个错位的细节、一次没有回应的呼喊。每个安静节拍必须完成一次可感知的压力积累，张力只升不泄；泄压必须是设计出来的（假警报、错误解脱），为下一次更高的峰值服务。
- 任何档位：时间轴前重后缓再收紧——开头变化最密，中段放宽，结尾再次加密；禁止把全片均分成等长块各装一件事。
- 连续高峰必须递增；中点用新信息转向故事（改变目标、关系或对过去的理解），不是把同一冲突重复得更响。同一个笑点、同一种威胁、同一层恐惧不升级地出现第二次，删。
- 情绪要运动：在紧张、好笑、温暖、恐惧、释然之间换挡，摆幅按题材校准——喜剧大开大合，恐怖在压迫与虚假松弛间交替，文艺片幅度可以极小但方向必须在走。不允许整片停在一个声部。

## 开场与结尾

- 开场是选择出来的，不是时间顺序的第一件事。从全片最具磁性、最只属于这个故事的时刻切入；需要时冷开场，后文自然回接。沉浸档的开场可以安静，但必须立刻建立「这里有什么不对」的特异性。
- 开场画面若能属于任何其他同类故事，重选；特异性优先于场面强度。禁止用设定说明、自我介绍、赶路、寒暄开场；前提信息在冲突或不安进行中带出。
- 开场承诺什么，正片就以至少同等强度兑现什么；不写正片接不住的标题党开场。
- 伏笔来自已建立的行为、物件与事实，兑现要「意料之外、回头必然」。反转必须改变人物处境、策略、关系或观众对已知事实的理解，不为密度而反转。
- 结尾让观众有事可做：重看、转发、争论、后怕、追下一集，或长久的余味。收束情节不等于完成结尾。

## 场景与正文

- 写故事本身，不写创作说明、导演说明、设定表或过程解释。
- 建立自然的集、幕、场结构但不固定数量；每场一个完整时空单元，按真实发生顺序排列，与前后场因果衔接。
- 每场包含明确地点、在场人物、可见行动、有效对白或旁白，以及情绪或信息推进；正文必须是可拍摄的完整场景，不是摘要。结构摘要负责预览，正文负责表演与叙事。
- 每个节拍造成一次可感变化：新问题、解答、新威胁、战术转变、地位或关系变化、新代价、感官异变、再语境化或不可逆行动。写完自问「这一拍为什么不是重复」，答不出就删或合并。
- 动作、停顿、反应和环境描写必须有表演价值，不以文字密度假装影视时长；感官与环境细节在沉浸档承担叙事功能，不是气氛填充。

## 对白锋利度

- 每句台词同时做两件事：表面话题之下有真实冲突或潜台词。只推剧情的是草稿，只装饰的是填充物，都要重写。
- 遮住人物名，应能凭语气、词汇和策略猜出说话人；猜不出说明人物没有独立声音。
- 人会打断、回避、答非所问、用具体细节当武器；优先用这个故事世界里的具体名词，不用抽象情绪词。
- 行为可以与台词矛盾，矛盾本身就是戏。沉默是一种动作——施压、拒绝、认出、划界——要有明确位置和功能。
- 禁止：复述已知事实、解释性台词、向观众说明功能、为凑时长加台词。

## 时长控制

- 用户指定时长时，完整剧本必须能在该时长内正常演完，不能只在标题或摘要中标注时长。语速与真实表演时长使用 `creative-core` 的「通用时长估算方法」，本 Skill 不另立数字。
- 一分钟对白密集内容的口播字数约 240–300 字；动作、停顿、气氛和复杂调度越多，对白应越少。时长来自对白、动作、反应、停顿和转场的实际时间，不来自幕数、场景数或节拍数。
- 同时发生的内容按同一时间轴计算，不按先后相加：画外音、内心独白、旁白与覆盖画面同时进行，人物可以边走边说、边打边喊。
- 超时先删次要情节、重复描写、冗长对白、多余动作和无效转场，优先保留用户核心事实、人物关系与主线。未指定时长时写成自然紧凑的作品，不自行宣称固定片长。

## 长故事与分段

- 先建立完整主线、人物目标、主要冲突、转折和结局，再按自然场景边界展开正文。
- 分段按故事顺序，元信息在同一集、同一幕内保持一致，不重复、跳号、倒序或互相冲突。单段是单一完整场景，不塞多个不连续时空，也不为格式机械截断不可分割的场景。
- 整体过长时保留原始来源和全局结构，局部展开携带该场入口状态、必须发生的事件与出口状态，避免各段独立改写世界事实。

## 忠实性与连续性

- 人物行动由已建立的欲望、限制和信息状态驱动；不让人物提前知道尚未发生的事实，不让失去、损坏或转移的物件无理由恢复。
- 重要身份、关系、地点特征、物件、目标、限制和已发生的状态变化一旦出现，后文保持一致。
- 场景转换需要因果或叙事目的；时间跳跃应使观众能理解已变化的状态。
- 类型、情绪和语言可以丰富，但不能覆盖用户已指定的故事目标。

## 自检

先查事实，再做盲评。盲评只看观众能看到的文本，忘掉创作理由——需要解释才成立的段落就是不成立。

- 事实：用户事实与目标时长是否全部保留？行为是否有因果？是否有跳变设定、提前获知或物件无理由复原？实际演出能否在目标时长内完成？
- 钩子：按本片档位，我本人会在时限内停下滑动、坐进故事吗？
- 逐段走时间轴，标出失速区间——抢夺注意力档找「会划走的段落」，沉浸档找「张力泄气的段落」（没有积累的安静、无功能的对白、重复的恐惧层级）。每一处都修。
- 高峰是否递增？中点是否转向？情绪是否在运动？
- 数「别的同类故事里不可能出现的时刻」，少于两个说明太通用。
- 对白遮名测试是否通过？结尾是否让观众有事可做？
- 任一条不及格，就地修改后再交付。不允许交付「正确但无聊」的版本。

## 边界

本 Skill 只负责剧本创作方法。唯一专业结果是运行时注入 schema 约束的 `outputKind: "screenplay"` 严格 JSON；完整剧本写入 `screenplayText`，摘要、来源、假设与开放问题写入各自固定字段，不另建 Markdown 剧本或第二份解释文件。不得在剧本中登记系统资产、生成 Resource ID、建立媒体任务或替资产设计决定视觉空间。

Creative Direction 可选。当前输入提供了精确方向 Resource 时，完整读取并使用会实质影响当前写作的领域，同时保持彼此协调；不得把制作政策复制成剧本元数据，也不得改变已经成立的故事事实。未提供时，根据用户要求和已提供故事事实工作，不得临时发明项目级方向。
