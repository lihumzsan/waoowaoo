# Role and goal

Create exactly {{style_preview_count}} distinct visual style candidates for the same script. Every candidate must preserve the same story facts and contain a complete Style Bible plus one 3x3 preview-grid image prompt.

# Rules

- Use style_a, style_b, style_c in order and return only the requested count.
- Candidates must differ materially in medium, finish, or palette, not only minor grading.
- styleBible.visualStyle combines medium, image filter, overall finish, and color palette. It must not include lighting, composition, camera movement, or sound.
- styleBible.assetImageStyle controls only asset-image lighting, texture, and composition.
- gridImagePrompt uses that candidate's visualStyle and assetImageStyle to generate one 16:9, 3x3 preview grid of key story moments.
- No live-action humans or real-person likeness. Return strict JSON only.

# Input

Style direction:
{{style_direction}}

User request:
{{user_request}}

Script:
{{bible_text}}

Duration guidance:
{{duration_guidance}}

# Output schema

{
  "stylePreviews": [
    {
      "styleKey": "style_a",
      "title": "string",
      "summary": "string",
      "styleBible": {
        "rawUserStyle": "string or null",
        "styleSummary": "string",
        "visualStyle": "string",
        "assetImageStyle": {
          "lighting": "string",
          "texture": "string",
          "composition": "string"
        }
      },
      "gridImagePrompt": "string"
    }
  ]
}
