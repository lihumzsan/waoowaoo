# 角色与目标

你负责通读下方的剧本原文，整理出这一集稳定成立的事实：完整的故事概览、主要人物、主要地点、长期设定，以及从文本中能看出的整体风格倾向。

只收录剧本中已经写明或能明确推断的事实，不要加入你自己的创作。只输出 JSON。

# 事实来源

- 下方剧本原文是唯一事实来源。
- 名称、身份、地点或规则在原文中找不到依据的，一律不写。
- 同一个人物或地点如果有多个称呼，合并成一个条目，把其余称呼写进 aliases。

# 工作规则

- synopsis 写完整的故事概览，覆盖主要冲突、人物关系、情绪走向和结局（或文本当前的终点）。
- title 和 logline 只在原文直接给出、或可以非常有把握地概括时才输出；没有把握就省略这两个字段。
- characters 只收录会反复出现或影响故事理解的人物；一次性提到的泛称、路人和纯环境描写不要立为人物。
- 每个 characters[].voiceProfile 必须是结构化的固有声纹档案，只描述角色稳定的声音本体，不描述当前台词表演。必须覆盖声龄印象、音高区间、音质色彩、共鸣位置、声线重量和声音纹理。
- voiceProfile 禁止写语速、停顿、音量、情绪、句尾处理、低声/喊叫/哭腔等动态说话状态；这些属于镜头表演或台词执行，不属于角色固有音色。
- voiceProfile 只能依据原文明示或人物身份、年龄、身体状态、长期性格气质等可明确支持的信息保守推断；不得引用具体演员、名人、品牌或受版权保护的声音。
- locations 只收录对空间连续、气氛或剧情推进有意义的地点；不要把普通物件或一次性的方位描述写成地点。
- entityId 要稳定、简短、可读，优先用英文小写加下划线，例如 `character_lin_xiaoyu`、`location_old_house`；同一实体不得重复出现。
- 不要输出字符下标或 firstSourceStart。人物和地点可输出 firstEvidence，由系统根据 blockId 与原文 quote 计算首次出现位置。
- firstEvidence.blockId 必须使用输入中的 `[p0001]` 这类块编号；firstEvidence.quote 必须是对应块中逐字存在的原文短句，不要改写、概括或加入省略号。
- worldRules 只写长期成立的世界规则、背景事实、限制条件或关系事实，不写一次性动作。
- styleGuide 必须从原文的题材、情绪、节奏和空间描写中归纳，不要写放之四海皆准的通用影像套话。
- 只输出下方 Schema 列出的字段，不要输出任何其他内容。

# 输入

带编号的剧本原文块：
{{source_document}}

# 自检

- 每一条信息在剧本原文中是否都有依据。
- 人物和地点是否去重，别名是否合并到同一条目。
- 每个主要人物是否都有可执行、稳定、非名人化的结构化 voiceProfile。
- voiceProfile 是否只写固有声纹，没有混入语速、音量、情绪、句尾处理或临场说话方式。
- entityId 是否稳定、简短、可读且没有重复。
- firstEvidence 的 blockId 是否来自输入块编号，quote 是否逐字存在于对应块中。
- styleGuide 是否来自原文归纳，而不是通用影像模板。
- 是否严格只输出了 Schema 列出的字段，且只有 JSON。
