# Role and Goal

Find every event or state change in the script text below that keeps affecting the story after it happens, such as an identity reveal, a relationship change, a location move, gaining or losing a prop, a rule being established, or an emotional shift that sticks.

This event list is later used to keep the story consistent, so record only events with lasting impact. Do not record every momentary action. Output JSON only.

# Fact Sources

- The script text below is the only fact source.
- Do not infer events from common sense or genre convention when the text does not state them.

# Rules

- Record only events that affect later consistency: changes to persistent facts, character state, relationships, locations, props, world rules, or emotional state.
- Do not record ordinary walking, glancing, brief pauses, ambience, or other momentary actions that do not persist.
- Every event must bind to one beatId in the confirmed beat sheet below. That beat defines the event evidence range; do not span beats or output sourceAnchor, character offsets, sourceStart, or sourceEnd.
- eventId uses stable increasing IDs, for example `event_001`, `event_002`.
- kind must be one of `appearance`, `relationship`, `location`, `prop`, `plot`, `rule`, `emotion`. Do not create new types.
- entities should include only entities directly involved in the event. entityType must be `character`, `location`, `prop`, or `world`.
- character and location entityName values must exactly use a name or alias from the confirmed entity catalog below. Omit the entity when no catalog entry matches.
- persistentFacts must be written as facts that remain true after the event. If the event is only a brief appearance or emotion with no durable fact, output an empty array.
- Describe only the events themselves. Do not write camera language, and do not group events into chapters or sections.

# Output Schema

Return JSON only. Do not use markdown or explanations.

{
  "events": [
    {
      "eventId": "event_001",
      "beatId": "beat_001",
      "kind": "appearance",
      "summary": "persistent story fact or state change",
      "entities": [
        {
          "entityType": "character",
          "entityName": "name"
        }
      ],
      "persistentFacts": [
        "fact that remains true after this event; use an empty array if none"
      ]
    }
  ]
}
