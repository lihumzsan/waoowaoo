# Role and Goal

Read the script text below, divide it into spans where the emotion stays relatively stable, and label each span with its dominant mood, intensity, and music tendency.

These labels are later used as music and pacing reference. You do not design the actual music; you only label emotion and music tendency. Output JSON only.

# Fact Sources

- The script text below is the only fact source.
- Do not add music styles, instruments, melodies, lyrics, or specific tracks the text does not support.

# Rules

- cues must be ordered by sourceStart.
- Each cue covers a span of text with relatively stable emotion or pacing. Do not create one cue for every sentence.
- sourceStart/sourceEnd is the half-open range `[sourceStart, sourceEnd)` of the span in the text, counted in UTF-16 code units (that is, JavaScript string indices).
- mood is a short emotional label, such as "suppressed doubt", "brief relief", or "danger approaching".
- intensity is a number from 0 to 1: 0 means almost no emotional pressure, 1 means maximum intensity. It must match the risk, conflict, emotional pressure, and action intensity in the text. Do not make every cue high intensity.
- musicPolicy must be one of four values: `none` means the span should likely have no music (for example long dialogue, information delivery, or quiet observation); `underscore` means low-presence atmospheric support; `theme` means thematic or character/concept motif music; `transition` means a bridge at a section shift or emotional turn.
- note briefly explains the reasoning; omit it when unnecessary.
- Do not write exact seconds, music duration, audio filenames, or mixing instructions.

# Input

Script text:
{{source_document}}

# Output Schema

Return JSON only. Do not use markdown or explanations.

{
  "cues": [
    {
      "cueId": "cue_001",
      "mood": "short mood label",
      "intensity": 0.6,
      "musicPolicy": "underscore",
      "note": "optional reason",
      "sourceStart": 0,
      "sourceEnd": 10
    }
  ]
}

# Self-check

- Are cues ordered by sourceStart?
- Are sourceStart/sourceEnd UTF-16 code-unit half-open ranges, with sourceEnd greater than sourceStart?
- Does musicPolicy use only `none`, `underscore`, `theme`, or `transition`?
- Is intensity between 0 and 1 and grounded in the text's emotion?
- Did you use `none` where music should likely be absent?
- Did you avoid instruments, lyrics, specific tracks, exact music duration, and mixing instructions?
- Is the response strict JSON only?
