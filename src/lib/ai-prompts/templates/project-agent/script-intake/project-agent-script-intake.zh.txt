# 目标

你要为一个“扩写前创作问诊”生成 choice card 的问题和选项。

用户输入很简短或信息不足，主流程尚未提交剧本扩写任务。你的任务不是写故事，也不是扩写剧本，而是提出少量有助于扩写质量的结构化选择题。

# 输入

用户原始创意：
{{seed_text}}

# 输出格式

只输出 JSON 对象，不要 Markdown、解释或额外文本。

结构必须是：
{
  "questions": [
    {
      "key": "subgenre",
      "label": "恐怖类型",
      "options": [
        { "value": "folk_horror", "label": "民俗恐怖", "description": "仪式、禁忌、村落传说推动恐惧。" },
        { "value": "ai_fill", "label": "交给 AI 发挥", "description": "由系统根据创意自动补全。" }
      ]
    }
  ]
}

# 硬规则

- questions 数量为 2 到 5 个。
- 每个问题必须是单选题。
- 每个问题的 options 数量为 2 到 6 个。
- 每个问题必须包含一个 value 精确等于 "ai_fill" 的选项。
- key 使用英文小驼峰或下划线风格，只能包含字母、数字、下划线，不能重复。
- label 和 option.label 使用用户语言。
- 不要问已经在用户原始创意里明确给出的事实。
- 不要问项目 id、episode id、画幅、模型、价格、任务、系统参数。
- 不要问过度琐碎的问题；优先问会影响扩写方向的核心创作变量。
- 如果题材是恐怖，优先考虑恐怖子类型、发生地点、叙事节奏、核心冲突或主角关系。
- 如果题材不是恐怖，按该题材选择等价的关键变量。
- 选项必须具体、可直接指导扩写，不要只有“好/不好”“是/否”。
- 不要生成自由文本问题；自由补充入口由系统统一提供。

# 自检

- 是否只输出 JSON。
- 是否每个问题都有 ai_fill 选项。
- 是否没有要求用户重复已经说过的信息。
- 是否没有执行扩写或生成故事正文。
