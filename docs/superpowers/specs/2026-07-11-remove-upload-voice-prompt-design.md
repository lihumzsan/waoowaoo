# 移除上传音色提示设计

## 目标

在所有音色上传和选择入口中彻底移除“上传音色仅可用于 IndexTTS”的浏览器确认框与提醒框。用户点击上传后直接打开文件选择器，选择已有上传音色后直接完成绑定。

## 范围

- 项目资产页的音色上传按钮不再调用 `window.confirm`。
- 内联发言人音色绑定中的两个上传入口不再调用 `window.confirm`。
- 选择已上传音色完成绑定后不再调用 `alert`。
- 删除中英文 `assets` 和 `voice` 翻译文件中的 `uploadQwenHint` 废弃文案。
- 不改变上传、绑定、IndexTTS 或 QwenTTS 的服务端规则和数据结构。

## 实现方式

直接删除三个前端入口中的提示辅助函数、条件分支和提醒调用，保留原有上传与绑定流程。加入一个回归测试，扫描相关组件和翻译资源，保证提示键、提示文案及其浏览器弹窗调用均已移除，同时确认上传入口仍直接触发文件选择器。

## 错误处理

原有上传失败、绑定失败和音频预览失败提示保持不变；只移除兼容性告知提示，不吞掉业务错误。

## 验收

- 点击所有上传音色入口均直接继续，不出现截图中的确认框。
- 选择已有上传音色后直接绑定，不出现相同提醒。
- 中英文资源中不再存在 `uploadQwenHint`。
- 回归测试、类型检查和相关 lint 检查通过。
